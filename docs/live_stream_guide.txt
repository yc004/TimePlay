===============================================
网页直播配置重要说明
===============================================

问题：为什么央视网页直播提示"浏览器不支持视频播放"？

原因：
1. 央视网站使用了特殊的视频播放技术
2. 需要特定的浏览器环境和插件
3. 可能需要用户交互才能播放
4. 网页版不适合自动化播放

===============================================
推荐解决方案
===============================================

方案1：使用直播流地址（强烈推荐）
-----------------------------------------
使用 m3u8 格式的直播流地址，系统会自动用VLC播放

优点：
✓ 播放稳定可靠
✓ 无需浏览器
✓ 自动播放
✓ 资源占用少
✓ 无广告干扰

配置示例：
{
  "type": "web",
  "url": "http://your-server.com/cctv13.m3u8"
}

如何获取直播流地址：
1. 搜索"CCTV直播源 m3u8"
2. 联系IPTV服务提供商
3. 使用浏览器开发者工具抓取

测试方法：
1. 打开VLC播放器
2. 媒体 -> 打开网络串流
3. 输入直播流URL
4. 如果能播放，说明地址有效

方案2：录制视频文件（最稳定）
-----------------------------------------
提前录制新闻节目，保存为视频文件

优点：
✓ 最稳定
✓ 不依赖网络
✓ 可精确控制内容
✓ 可反复使用

配置示例：
{
  "type": "video",
  "path": "videos/morning_news.mp4"
}

方案3：使用网页版（不推荐）
-----------------------------------------
系统已经尽力优化网页播放，但仍可能遇到问题

如果必须使用网页版：
1. 确保网络连接稳定
2. 可能需要手动点击播放
3. 建议提前测试
4. 准备备用方案

===============================================
实际部署建议
===============================================

校园闭路电视系统建议：

1. 主要内容使用视频文件
   - 校园宣传片
   - 安全教育视频
   - 通知公告视频

2. 新闻节目使用直播流
   - 获取稳定的m3u8直播源
   - 联系当地广电部门
   - 或使用IPTV服务

3. 准备备用内容
   - 当直播失败时播放备用视频
   - 系统会自动切换
