【使用方法】

方法1: 通过启动器（推荐）
1. 双击运行: scripts\launcher.bat
2. 点击"播放时间表管理"按钮
3. 时间表管理窗口会打开

方法2: 直接启动
双击运行: test_gui_manager.bat

方法3: 命令行启动
python src\ui\gui_manager.py

===============================================

【功能说明】

时间表管理界面提供以下功能:

1. 添加任务
   - 设置任务名称
   - 设置开始/结束时间
   - 选择播放星期
   - 选择内容类型(视频/网页/轮播)
   - 设置全屏/置顶选项

2. 编辑任务
   - 选择任务后点击"编辑"
   - 修改任务参数
   - 保存更改

3. 删除任务
   - 选择任务后点击"删除"
   - 确认删除

4. 保存配置
   - 点击"保存配置"按钮
   - 配置保存到 config/schedule.json

===============================================

【内容类型】

1. video - 视频文件
   - 选择本地视频文件
   - 支持 mp4, avi, mkv, flv 等格式

2. web - 网页直播
   - 输入直播页面URL
   - 例如: https://tv.cctv.com/live/cctv13/
   - 系统会自动使用Selenium播放器

3. playlist - 轮播列表
   - 点击"编辑轮播列表"
   - 添加多个视频或网页
   - 设置循环播放

===============================================

【配置文件】

位置: config/schedule.json

格式:
{
  "schedules": [
    {
      "id": 1,
      "name": "早间新闻",
      "start_time": "07:00",
      "end_time": "07:30",
      "weekdays": [1, 2, 3, 4, 5],
      "type": "web",
      "url": "https://tv.cctv.com/live/cctv13/",
      "fullscreen": true,
      "topmost": true,
      "enabled": true
    }
  ]
}

【故障排除】

Q: 点击按钮后没有窗口打开？
A: 
1. 检查是否有错误提示框
2. 运行 test_gui_manager.bat 测试
3. 查看是否有Python错误信息

Q: 窗口打开但是空白？
A:
1. 检查 config/schedule.json 是否存在
2. 如果不存在，会显示空列表
3. 点击"添加任务"创建第一个任务

Q: 保存配置失败？
A:
1. 检查 config 目录是否存在
2. 检查是否有写入权限
3. 查看错误提示信息
