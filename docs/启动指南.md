# 校园闭路电视播放系统 - 启动指南

## 快速启动

### 方式1：使用启动器（推荐）
```
双击运行：scripts/launcher.bat
```
启动器提供图形界面，可以：
- 启动/停止播放系统
- 配置显示器
- 管理播放时间表
- 设置开机自启动
- 测试播放功能

### 方式2：直接启动播放系统
```
双击运行：scripts/start.bat
```
直接启动播放系统，按照配置的时间表自动播放

## 首次使用步骤

### 1. 安装依赖
```
双击运行：scripts/install.bat
```
系统会自动安装所需的Python库

### 2. 配置显示器
```
双击运行：scripts/display_settings.bat
```
或在启动器中点击"显示器配置"

配置步骤：
1. 查看可用显示器列表
2. 选择显示模式（全屏/自定义窗口）
3. 测试显示效果
4. 保存配置

### 3. 配置播放时间表
```
双击运行：scripts/manager.bat
```
或在启动器中点击"播放时间表管理"

配置步骤：
1. 点击"添加任务"
2. 填写任务信息（名称、时间、星期）
3. 选择内容类型（视频/网页/轮播）
4. 配置播放内容
5. 保存配置

### 4. 准备视频文件
将视频文件放入 `videos/` 目录

### 5. 启动系统
```
双击运行：scripts/start.bat
```
或在启动器中点击"启动播放系统"

## 常用功能

### 管理播放时间表
```
scripts/manager.bat
```
- 添加/编辑/删除播放任务
- 配置轮播列表
- 选择播放星期
- 启用/禁用任务

### 配置显示器
```
scripts/display_settings.bat
```
- 选择播放的显示器
- 设置窗口位置和大小
- 测试显示效果
- 支持多显示器拼接

### 设置开机自启动
在启动器中点击"开机自启动设置"
或运行：
```
python src/utils/auto_start.py
```

### 测试功能
- 测试播放器：`scripts/test_player.bat`
- 测试显示配置：`scripts/test_display.bat`
- 测试流提取：`scripts/test_stream_extractor.bat`

## 配置文件位置

所有配置文件在 `config/` 目录：
- `schedule.json` - 播放时间表
- `display_config.json` - 显示配置
- `live_streams.json` - 直播源示例

## 日志文件

日志文件自动保存在 `logs/` 目录
- 文件名格式：`tv_system_YYYYMMDD.log`
- 包含所有系统运行信息
- 用于故障排查

## 故障排除

### 系统无法启动
1. 检查Python是否安装
2. 运行 `scripts/install.bat` 安装依赖
3. 查看 `logs/` 目录下的日志文件

### 视频无法播放
1. 检查VLC播放器是否安装
2. 检查视频文件路径是否正确
3. 使用测试工具验证

### 直播无法播放
1. 检查网络连接
2. 查看日志文件
3. 参考 `docs/stream_helper.md`

### 显示位置不对
1. 运行 `scripts/display_settings.bat`
2. 重新配置显示器
3. 使用"测试显示"功能验证

## 技术支持

遇到问题请：
1. 查看日志文件：`logs/tv_system_YYYYMMDD.log`
2. 阅读相关文档：`docs/` 目录
3. 使用测试工具排查问题

## 系统要求

- Windows 7/10/11
- Python 3.8+
- VLC 媒体播放器
- 2GB+ 内存
- 稳定的网络连接（播放直播时）
