# 播放时间表配置说明

## 配置文件格式

配置文件为 `schedule.json`，采用 JSON 格式。

## 基本结构

```json
{
  "schedules": [
    {任务1},
    {任务2},
    ...
  ]
}
```

## 任务配置参数

### 必填参数

- `id`: 任务唯一标识（整数）
- `name`: 任务名称（字符串）
- `start_time`: 开始时间，格式 "HH:MM"（24小时制）
- `end_time`: 结束时间，格式 "HH:MM"（24小时制）
- `type`: 内容类型，可选值：
  - `"video"`: 视频文件
  - `"web"`: 网页直播流
  - `"playlist"`: 轮播列表

### 可选参数

- `weekdays`: 播放的星期，数组，1=周一，7=周日
  - 默认值：`[1, 2, 3, 4, 5, 6, 7]`（每天）
  - 示例：`[1, 2, 3, 4, 5]`（工作日）
  - 示例：`[6, 7]`（周末）

- `fullscreen`: 是否全屏播放（布尔值）
  - 默认值：`true`

- `topmost`: 是否窗口置顶（布尔值）
  - 默认值：`true`

- `enabled`: 是否启用此任务（布尔值）
  - 默认值：`true`

### 类型特定参数

#### video 类型

- `path`: 视频文件路径（字符串，必填）
  - 示例：`"videos/campus_intro.mp4"`

#### web 类型

- `url`: 网页直播流地址（字符串，必填）
  - 示例：`"https://tv.cctv.com/live/cctv13/"`

#### playlist 类型

- `playlist`: 轮播项目列表（数组，必填）
  - 每个项目包含：
    - `type`: `"video"` 或 `"web"`
    - `path` 或 `url`: 内容路径
    - `duration`: 播放时长（秒）

- `loop`: 是否循环播放轮播列表（布尔值）
  - 默认值：`true`

## 时间段说明

### 时间格式

- 使用24小时制
- 格式：`"HH:MM"`
- 示例：`"07:00"`, `"19:30"`

### 时间段行为

- 系统会在 `start_time` 到 `end_time` 之间持续播放
- 对于单个视频/网页，会一直播放到结束时间
- 对于轮播列表：
  - 按顺序播放列表中的项目
  - 每个项目播放指定的 `duration` 时长
  - 如果 `loop` 为 `true`，播放完所有项目后会重新开始
  - 到达 `end_time` 时自动停止

### 跨天时间段

如果需要跨越午夜的时间段，例如 23:00 到 01:00：

```json
{
  "start_time": "23:00",
  "end_time": "01:00"
}
```

系统会自动处理跨天情况。

## 星期配置

### 星期编号

- 1 = 星期一
- 2 = 星期二
- 3 = 星期三
- 4 = 星期四
- 5 = 星期五
- 6 = 星期六
- 7 = 星期日

### 常用配置

- 工作日：`[1, 2, 3, 4, 5]`
- 周末：`[6, 7]`
- 每天：`[1, 2, 3, 4, 5, 6, 7]`
- 仅周一：`[1]`
- 周一、三、五：`[1, 3, 5]`

## 轮播列表详解

### 轮播工作原理

1. 系统按顺序播放列表中的每个项目
2. 每个项目播放指定的时长
3. 播放完一个项目后自动切换到下一个
4. 如果启用循环，播放完最后一个后回到第一个
5. 到达结束时间时停止播放

### 轮播项目配置

每个轮播项目需要包含：

```json
{
  "type": "video",           // 或 "web"
  "path": "videos/xxx.mp4",  // 视频用path，网页用url
  "duration": 300            // 播放时长（秒）
}
```

### 轮播时长计算

假设有3个视频，每个5分钟（300秒）：
- 完整播放一轮需要：15分钟
- 如果时间段是30分钟，会播放2轮
- 如果时间段是20分钟，会播放1轮+第1个视频

## 注意事项

1. **时间冲突**：避免多个任务的时间段重叠
2. **文件路径**：确保视频文件路径正确且文件存在
3. **网络连接**：播放网页直播需要稳定的网络
4. **时长设置**：轮播项目的时长应合理，不要过长或过短
5. **JSON格式**：确保配置文件符合JSON格式规范
6. **编码格式**：配置文件使用UTF-8编码

## 配置验证

修改配置后，建议：

1. 使用JSON验证工具检查格式
2. 在管理界面中查看是否正确加载
3. 测试播放功能是否正常

## 热重载

修改配置文件后，可以通过以下方式重新加载：

1. 重启系统
2. 使用远程控制API的reload接口
3. 在管理界面中重新打开

## 常见问题

### Q: 为什么任务没有执行？

检查：
- `enabled` 是否为 `true`
- `weekdays` 是否包含当前星期
- 当前时间是否在 `start_time` 和 `end_time` 之间
- 配置文件格式是否正确

### Q: 轮播不循环怎么办？

确保 `loop` 设置为 `true`

### Q: 如何临时禁用某个任务？

将该任务的 `enabled` 设置为 `false`

### Q: 可以同时播放多个任务吗？

不可以，系统同一时间只能播放一个任务。如果时间段重叠，会按照配置文件中的顺序选择第一个匹配的任务。
