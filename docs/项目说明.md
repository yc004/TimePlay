# 校园闭路电视播放系统 - 项目说明

## 项目简介
基于Python和PyQt5的自动化电视播放系统，支持视频文件和网页直播的定时播放。

## 核心功能

### 1. 多种播放方式
- **视频文件播放**：支持本地视频文件播放（使用VLC）
- **直播流播放**：支持m3u8、flv等直播流格式
- **网页直播播放**：支持网页直播（使用Selenium + Chrome）

### 2. 播放模式
- **Kiosk全屏模式**：完全全屏，隐藏所有浏览器UI
- **窗口模式**：自定义窗口大小和位置，隐藏地址栏

### 3. 时间表管理
- 支持按时间段自动播放
- 支持按星期设置播放计划
- 支持轮播列表
- 支持单次和循环播放

### 4. 空闲窗口
- 无播放任务时显示黑屏和时钟
- 自动切换到播放内容
- 播放结束后自动返回空闲窗口

### 5. 显示器配置
- 支持多显示器环境
- 支持全屏和自定义窗口模式
- 支持窗口位置和大小配置

### 6. 系统管理
- 图形化启动器
- 时间表管理界面
- 显示器配置界面
- 开机自启动设置

## 技术特点

### 反爬虫绕过
- 使用Selenium模拟真实浏览器
- 移除webdriver标识
- 自定义User-Agent
- 支持CCTV等网站的直播播放

### 自动播放和全屏
- 自动检测并播放视频
- 自动点击播放按钮
- 强制视频全屏显示
- CSS强制全屏支持

### 稳定性保障
- 看门狗机制监控播放状态
- 自动重启失败的播放
- 错误日志记录
- 异常处理和恢复

## 配置说明

### 播放模式配置（schedule.json）
```json
{
  "schedules": [
    {
      "name": "CCTV13直播",
      "type": "web",
      "url": "https://tv.cctv.com/live/cctv13/",
      "fullscreen": true,     // true=全屏, false=窗口模式
      "start_time": "08:00",
      "end_time": "18:00",
      "weekdays": [1,2,3,4,5], // 1=周一, 7=周日
      "enabled": true
    }
  ]
}
```

### 显示器配置（display_config.json）
```json
{
  "display_mode": "custom",  // fullscreen或custom
  "screen_index": 0,         // 显示器索引
  "window_geometry": {
    "x": 100,
    "y": 100,
    "width": 1304,
    "height": 742
  }
}
```

## 播放模式说明

### Kiosk全屏模式（fullscreen: true）
- 完全全屏，占满整个屏幕
- 完全隐藏浏览器UI
- 无窗口边框
- 适合固定设备的全屏播放

### 窗口模式（fullscreen: false）
- 自定义窗口大小和位置
- 隐藏地址栏和工具栏
- 有窗口边框
- 适合需要精确控制窗口大小的场景

## 故障排除

### 1. ChromeDriver问题
```bash
# 重新安装ChromeDriver
python install_chromedriver.py

# 或手动下载
# 访问: https://chromedriver.chromium.org/
```

### 2. 网页直播无法播放
- 检查网络连接
- 确认URL正确
- 查看日志文件（logs/tv_system_*.log）
- 尝试使用浏览器手动访问URL

### 3. 窗口大小不正确
- 检查display_config.json配置
- 使用显示器配置工具重新设置
- 确认fullscreen参数设置正确

### 4. 空闲窗口不显示
- 检查main.py或start_with_selenium.py中show_idle_window参数
- 确认空闲窗口未被其他窗口遮挡
- 查看日志确认空闲窗口是否创建
