# 空闲窗口功能说明

## 功能概述

系统启动后会始终显示一个播放窗口：
- **有播放任务时**：显示播放内容（视频/直播）
- **无播放任务时**：显示黑屏+时钟

## 实现原理

### 空闲窗口 (IdleWindow)

位置：`src/core/idle_window.py`

特性：
- 全屏黑色背景
- 显示当前时间（暗色，不刺眼）
- 自动应用显示配置
- 窗口置顶

### 播放器集成

位置：`src/core/player.py`

工作流程：
```
系统启动
  ↓
创建并显示空闲窗口（黑屏）
  ↓
有播放任务？
  ├─ 是 → 隐藏空闲窗口 → 显示播放内容
  └─ 否 → 保持显示空闲窗口
  ↓
播放结束
  ↓
重新显示空闲窗口（黑屏）
```

## 使用方法

### 启用空闲窗口（默认）

```python
# main.py 或 start_with_selenium.py
player = MediaPlayer(show_idle_window=True)  # 启用
```

### 禁用空闲窗口

```python
player = MediaPlayer(show_idle_window=False)  # 禁用
```

## 技术细节

### 窗口管理

```python
class MediaPlayer:
    def __init__(self, show_idle_window=True):
        self.idle_window = None
        if show_idle_window:
            self._create_idle_window()
            self._show_idle_window()
    
    def play_video(self, ...):
        self._hide_idle_window()  # 隐藏空闲窗口
        # 播放视频
    
    def stop_current(self):
        # 停止播放
        self._show_idle_window()  # 重新显示空闲窗口
```

### 时钟更新

```python
def update_clock(self):
    """每秒更新一次"""
    current_time = datetime.now().strftime("%H:%M:%S")
    self.clock_label.setText(current_time)
```

### 资源清理

```python
def cleanup(self):
    """系统关闭时清理"""
    self.stop_clock()
    self.close()
```

## 常见问题

### Q1: 空闲窗口不显示？

**检查：**
1. 确认 `show_idle_window=True`
2. 检查日志：`logs/tv_system_YYYYMMDD.log`
3. 查找 "空闲窗口已创建" 日志

**解决：**
```python
# 在 main.py 或 start_with_selenium.py 中
player = MediaPlayer(show_idle_window=True)
```

### Q2: 时钟不更新？

**原因：** 定时器未启动

**检查：**
```python
# 在 idle_window.py 的 init_ui 方法中
self.start_clock()  # 确保调用
```

### Q3: 空闲窗口不是全屏？

**原因：** 显示配置问题

**解决：**
1. 检查 `config/display_config.json`
2. 确认 `display_mode` 设置为 `fullscreen`
3. 或运行显示设置工具配置

### Q4: 播放结束后不显示空闲窗口？

**原因：** `stop_current` 方法未调用 `_show_idle_window`

**检查：**
```python
def stop_current(self):
    # ... 停止播放代码
    self._show_idle_window()  # 确保调用
```

### Q5: 想要纯黑屏，不显示时钟？

**解决：**

在 `src/core/idle_window.py` 中：

```python
def init_ui(self):
    # ...
    
    # 注释掉时钟相关代码
    # self.clock_label = QLabel()
    # ...
    # layout.addWidget(self.clock_label)
    
    # 不启动时钟
    # self.start_clock()
```

或者设置时钟为完全透明：

```python
self.clock_label.setStyleSheet("""
    color: transparent;  # 完全透明
""")
```

## 性能考虑

### 资源占用

- 空闲窗口非常轻量
- 只有一个QWidget和一个QLabel
- 时钟更新每秒一次，CPU占用极低

### 内存占用

- 空闲窗口常驻内存
- 约占用 < 10MB 内存
- 不影响播放性能
