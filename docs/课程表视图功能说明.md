# 课程表视图功能说明

## 概述

时间表管理器现在支持两种视图模式：
1. **列表视图** - 传统的表格显示，适合详细查看和编辑
2. **课程表视图** - 类似课程表的直观显示，适合快速浏览时间安排

## 功能特性

### 1. 双视图模式

#### 列表视图
- 表格形式显示所有任务
- 显示完整的任务信息
- 支持排序和筛选
- 适合详细编辑

#### 课程表视图
- 按星期和时间段显示
- 直观的时间表布局
- 颜色区分不同状态
- 快速查看时间安排

### 2. 时间段划分

默认时间段（2小时一段）：
- 06:00-08:00 早晨
- 08:00-10:00 上午
- 10:00-12:00 上午
- 12:00-14:00 中午
- 14:00-16:00 下午
- 16:00-18:00 下午
- 18:00-20:00 傍晚
- 20:00-22:00 晚上

### 3. 视觉设计

#### 颜色方案
- **表头**: 蓝色背景 (#2196F3)，白色文字
- **星期标签**: 浅蓝色背景 (#E3F2FD)，深蓝色文字
- **有任务格子**: 黄色背景 (#FFF9C4)，黄色边框
- **空白格子**: 灰色背景 (#FAFAFA)，灰色边框
- **任务卡片**: 白色背景，圆角边框

#### 任务卡片显示
- 任务名称（粗体，蓝色）
- 时间段（灰色，小字）
- 类型和内容（浅灰色，更小字）

### 4. 智能时间匹配

系统会自动：
- 检测任务时间与时间段的重叠
- 在对应的格子中显示任务
- 支持跨时间段的任务
- 支持同一时间段多个任务

## 使用方法

### 切换视图

1. **切换到列表视图**
   - 点击"列表视图"单选按钮
   - 显示传统表格

2. **切换到课程表视图**
   - 点击"课程表视图"单选按钮
   - 显示课程表布局

### 查看任务

#### 在课程表视图中
1. 找到对应的星期行
2. 找到对应的时间段列
3. 查看该格子中的任务卡片
4. 任务卡片显示：
   - 任务名称
   - 具体时间
   - 任务类型

#### 任务状态
- 有任务：黄色背景，显示任务卡片
- 无任务：灰色背景，显示"—"

### 编辑任务

课程表视图是只读的，要编辑任务：
1. 切换到列表视图
2. 选择要编辑的任务
3. 点击"编辑任务"按钮或双击任务行
4. 在对话框中修改
5. 切换回课程表视图查看更新

```python
# 创建星期行

```

### 时间匹配算法

```python
def _time_overlaps(self, slot_start, slot_end, task_start, task_end):
    """检查时间段是否重叠"""
    # 转换为分钟数
    slot_start_min = slot_start.hour() * 60 + slot_start.minute()
    slot_end_min = slot_end.hour() * 60 + slot_end.minute()
    task_start_min = task_start.hour() * 60 + task_start.minute()
    task_end_min = task_end.hour() * 60 + task_end.minute()
    
    # 检查重叠：任务结束时间 > 时间段开始 且 任务开始时间 < 时间段结束
    return not (task_end_min <= slot_start_min or task_start_min >= slot_end_min)
```

### 数据流

```

    ↓

    ↓

    ↓

    ↓
遍历每个时间段
    ↓
查找匹配的任务
    ↓
```


## 注意事项

1. **性能考虑**
   - 任务数量较多时，课程表视图可能需要更多渲染时间
   - 建议任务数量控制在50个以内

2. **时间段设置**
   - 时间段不能重叠
   - 时间段应该连续覆盖一天
   - 建议使用2小时或更长的时间段

3. **任务显示**
   - 跨多个时间段的任务会在每个时间段都显示
   - 同一时间段的多个任务会垂直排列
   - 任务名称过长会自动换行

4. **编辑限制**
   - 课程表视图是只读的
   - 需要切换到列表视图进行编辑
   - 编辑后自动更新课程表视图

## 故障排除

### 课程表显示空白
- 检查是否有启用的任务
- 确认任务时间在显示的时间段内
- 检查weekdays配置是否正确

### 任务显示位置不对
- 检查任务的开始和结束时间
- 确认时间格式正确（HH:mm）
- 查看日志中的时间匹配信息

### 切换视图失败
- 重启应用程序
- 检查配置文件格式
- 查看错误日志
