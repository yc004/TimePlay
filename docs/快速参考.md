## 看门狗功能

### 配置位置
`config/config.py` 中的 `SAFETY_CONFIG`

### 关键参数
```python
'enable_watchdog': True,    # 启用/禁用看门狗
'check_interval': 30,       # 检查间隔（秒）
'enable_heartbeat': True,   # 启用心跳检查
```

### 看门狗能做什么
- ✅ 播放窗口被关闭 → 自动恢复
- ✅ 播放器崩溃 → 自动重启
- ✅ 播放内容错误 → 自动恢复
- ❌ 进程被终止 → 无法恢复（已通过隐藏控制台避免）

## 日志查看

### 日志位置
```
logs/tv_system_YYYYMMDD.log
```

### 重要日志关键词
- `系统启动成功` - 系统已启动
- `检测到播放异常` - 看门狗检测到问题
- `系统恢复完成` - 看门狗恢复成功
- `开始执行任务` - 任务开始播放
- `ERROR` - 错误信息

## 播放任务配置

### 时间表文件
`config/schedule.json`

### 任务结构
```json
{
  "name": "任务名称",
  "enabled": true,
  "start_time": "08:00",
  "end_time": "10:00",
  "weekdays": [1, 2, 3, 4, 5],
  "type": "playlist",
  "playlist": [
    {
      "type": "video",
      "path": "videos/test.mp4",
      "duration": 300,
      "loop": false
    }
  ],
  "fullscreen": true,
  "topmost": true,
  "loop": true
}
```

### 媒体类型
- `video` - 视频文件（MP4、AVI等）
- `image` - 图片文件（JPG、PNG等）
- `web` - 网页直播（URL）

### 星期编号
- 1 = 周一
- 2 = 周二
- 3 = 周三
- 4 = 周四
- 5 = 周五
- 6 = 周六
- 7 = 周日

## 常见问题快速解决

### 问题：启动后显示控制台窗口
**解决**：确保使用启动器启动，不要直接运行 Python 脚本

### 问题：看门狗没有恢复
**检查**：
1. 日志中是否有"检测到播放异常"
2. `config/config.py` 中 `enable_watchdog` 是否为 `True`
3. 是否在播放时间段内

### 问题：浏览器无法关闭
**解决**：
```bash
pip install psutil
```

### 问题：网页直播启动慢
**已修复**：现在直接使用系统 ChromeDriver，1-2秒启动

### 问题：任务时间重叠
**已修复**：保存时会自动检查并提示冲突

## 命令行快捷方式

### 查看日志（实时）
```bash
# Windows PowerShell
Get-Content logs\tv_system_*.log -Wait -Tail 50

# 或使用记事本打开并刷新
notepad logs\tv_system_YYYYMMDD.log
```

### 检查进程
```bash
# 查看 Python 进程
tasklist | findstr python

# 结束进程（如果需要）
taskkill /F /IM pythonw.exe
```

### 清理日志
```bash
# 删除旧日志（保留最近7天）
forfiles /P logs /M *.log /D -7 /C "cmd /c del @path"
```

## 性能优化

### 减少 CPU 占用
1. 增大看门狗检查间隔：`check_interval: 60`
2. 禁用不需要的功能

### 减少内存占用
1. 使用合适的视频分辨率
2. 避免过大的图片文件
3. 及时清理旧日志

### 提高启动速度
1. 使用本地视频而非网络视频
2. 预先安装 ChromeDriver
3. 减少启动时的检查项

- Python 3.7+

## 提示和技巧

### 提示1：使用相对路径
在配置文件中使用相对路径，便于移动系统目录：
```json
"path": "videos/test.mp4"  // 推荐
"path": "C:/path/to/videos/test.mp4"  // 不推荐
```

### 提示2：测试播放内容
在添加到时间表前，先使用"播放器测试"功能测试

### 提示3：合理安排任务时间
- 避免任务时间重叠（系统会自动检查）
- 预留任务切换时间（建议间隔1-2分钟）
- 考虑播放内容的实际时长

### 提示4：定期备份
每周备份一次配置文件，避免意外丢失

### 提示5：监控日志
定期查看日志，及时发现潜在问题

### 提示6：优化视频文件
- 使用 H.264 编码的 MP4 格式
- 分辨率匹配显示器
- 码率适中（不要过高）

### 提示7：网页直播注意事项
- 确保网络连接稳定
- 使用可靠的直播源
- 定期检查直播源是否有效

### 提示8：空闲窗口
启用空闲窗口可以：
- 避免显示桌面
- 显示当前时间
- 提供专业的待机画面

### 提示9：看门狗配置
- 检查间隔不要太小（建议30-60秒）
- 启用心跳检查可以检测主循环卡死
- 查看日志了解看门狗工作情况

### 提示10：开机自启动
设置开机自启动后：
- 确保配置文件路径正确
- 测试重启后是否正常启动
- 考虑添加启动延迟（等待网络连接）
