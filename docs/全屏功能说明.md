# 全屏功能说明

## 功能概述

系统现在支持多种全屏方式，确保直播页面的视频播放器能够真正全屏显示。

## 全屏实现策略

### 问题分析

用户反馈：浏览器窗口确实全屏了，但是页面内的直播画面没有全屏。

这是因为：
1. 浏览器窗口全屏 ≠ 视频播放器全屏
2. 网页内的视频播放器是一个独立的元素，需要单独设置全屏
3. 某些网站的播放器可能被其他页面元素（导航栏、侧边栏等）包围

### 解决方案

系统采用多层全屏策略：

1. **浏览器窗口全屏** - Kiosk模式
2. **视频元素全屏** - JavaScript Fullscreen API
3. **CSS强制全屏** - 当API失败时，使用CSS强制播放器占满屏幕

## 全屏方法

### 方法1: CSS强制播放器全屏（最可靠）⭐

这是解决"浏览器全屏但视频不全屏"问题的关键方法：

```javascript
function forcePlayerFullscreen() {
    // 查找播放器容器
    var playerSelectors = [
        '.player',
        '.video-player',
        '[class*="player"]',
        '[id*="player"]',
        'video'
    ];
    
    // 找到播放器后，强制设置为全屏
    player.style.position = 'fixed';
    player.style.top = '0';
    player.style.left = '0';
    player.style.width = '100vw';
    player.style.height = '100vh';
    player.style.zIndex = '999999';
    
    // 隐藏页面其他内容
    document.body.style.overflow = 'hidden';
}
```

**执行时机：**
- 页面加载后3秒
- 在尝试Fullscreen API之后1秒
- 确保即使API失败，播放器也能全屏

**优点：**
- 不受浏览器安全策略限制
- 适用于所有网站
- 可以隐藏页面其他元素

### 方法2: JavaScript Fullscreen API

标准的全屏API，优先尝试：

```javascript
// 视频元素全屏
video.requestFullscreen()

// 或整个文档全屏
document.documentElement.requestFullscreen()
```

**限制：**
- 需要用户交互触发（点击事件）
- 某些网站可能阻止
- 可能被浏览器安全策略拦截

### 方法3: 点击页面全屏按钮

自动查找并点击页面上的全屏按钮：

```javascript
var selectors = [
    'button[class*="fullscreen"]',
    '[aria-label*="全屏"]',
    '[title*="全屏"]',
    '.vjs-fullscreen-control'
];
```

### 方法4: Kiosk模式（浏览器窗口全屏）

Chrome启动时使用kiosk模式，浏览器窗口自动全屏无边框：

```python
chrome_options.add_argument('--kiosk')
```

**优点:**
- 启动即全屏
- 无浏览器边框
- 无法退出全屏（除非关闭）

**适用场景:**
- 电视播放系统
- 公共显示屏
- 无人值守系统

## 完整的全屏流程

系统启动后的全屏执行顺序：

```
1. Chrome启动（Kiosk模式）
   ↓ 浏览器窗口全屏，无边框
   
2. 加载直播页面
   ↓ 等待页面加载完成
   
3. 立即执行
   ↓ playVideos() - 播放所有视频
   ↓ clickPlayButtons() - 点击播放按钮
   
4. 延迟3秒后
   ↓ clickFullscreenButtons() - 查找并点击全屏按钮
   ↓ 如果没找到按钮 → tryFullscreen() - 使用API
   
5. 再延迟1秒后（共4秒）
   ↓ forcePlayerFullscreen() - CSS强制播放器全屏 ⭐
   ↓ 设置播放器容器为fixed, 100vw x 100vh
   ↓ 隐藏页面其他元素
   
6. 定期重试（每2秒）
   ↓ 持续尝试播放视频
   ↓ 直到视频播放或重试10次
```

**关键点：**
- 第5步的CSS强制全屏是解决"浏览器全屏但视频不全屏"的关键
- 即使Fullscreen API失败，CSS方法也能确保播放器占满屏幕
- 通过隐藏其他元素，确保只显示视频内容

### 方法5: 手动触发全屏

如果自动全屏失败，可以手动触发：

```python
player.enter_fullscreen()  # JavaScript API
player.send_fullscreen_key()  # F11键
```

## 常见问题

### Q1: 浏览器全屏了但视频播放器没有全屏 ⭐

**这是最常见的问题！**

**原因:** 
- 浏览器窗口全屏 ≠ 视频播放器全屏
- 网页内的播放器是独立元素，需要单独设置

**解决:** 
系统已经实现了CSS强制全屏功能，会在页面加载4秒后自动执行：
```javascript
forcePlayerFullscreen()  // 强制播放器占满屏幕
```

如果还是不行，可能需要针对特定网站调整播放器选择器。

### Q2: 自动全屏不生效

**可能原因:**
- 浏览器安全策略限制
- 页面未完全加载
- 视频元素未找到

**解决方法:**
1. 使用CSS强制全屏（已自动启用）⭐
2. 使用Kiosk模式（已启用）
3. 增加延迟时间
4. 检查JavaScript控制台日志

### Q3: 全屏后仍有浏览器边框

**原因:** 未启用Kiosk模式

**解决:** 启用Kiosk模式
```python
chrome_options.add_argument('--kiosk')
```

### Q4: 无法退出全屏

**原因:** Kiosk模式下无法退出

**解决:** 
- 关闭浏览器窗口
- 或禁用Kiosk模式

### Q5: 页面其他元素（导航栏、侧边栏）没有隐藏

**原因:** CSS强制全屏可能没有正确执行

**解决:** 
检查浏览器控制台，确认 `forcePlayerFullscreen()` 已执行。
可能需要针对特定网站调整选择器。

### Q6: 全屏后视频不在中心或变形

**原因:** 页面布局问题

**解决:** 使用 `object-fit: contain` 保持比例
```javascript
video.style.objectFit = 'contain';  // 已自动设置
```

### Q7: 多显示器环境下全屏到错误的屏幕

**原因:** Chrome默认在主显示器全屏

**解决:** 
1. 设置窗口位置到目标显示器
2. 然后触发全屏

```python
player = SeleniumPlayerAuto(
    url=url,
    fullscreen=True,
    position=(1920, 0),  # 第二个显示器
    size=(1920, 1080)
)
```

## 最佳实践

### 1. 使用Kiosk模式

最可靠的全屏方案：

```python
chrome_options.add_argument('--kiosk')
```

### 2. 隐藏鼠标光标

全屏时隐藏光标：

```javascript
document.body.style.cursor = 'none';
```

### 3. 禁用视频控制条

避免用户操作：

```javascript
video.controls = false;
```

### 4. 监听全屏退出

防止意外退出全屏：

```javascript
document.addEventListener('fullscreenchange', function() {
    if (!document.fullscreenElement) {
        // 重新进入全屏
        tryFullscreen();
    }
});
```

### 5. 多显示器配置

正确设置窗口位置：

```python
# 获取显示配置
geometry = display_config.get_display_geometry()

player = SeleniumPlayerAuto(
    url=url,
    fullscreen=True,
    position=(geometry['x'], geometry['y']),
    size=(geometry['width'], geometry['height'])
)
```
