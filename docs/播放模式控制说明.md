# 播放模式控制说明

## 功能说明
通过时间表中的"全屏"选项直接控制播放模式：
- **勾选全屏**：使用Kiosk全屏模式，完全隐藏浏览器UI，占满整个屏幕
- **不勾选全屏**：使用App模式，按display_config配置的大小显示，隐藏地址栏

## 配置方法

### 方法1：使用GUI管理器（推荐）

#### 步骤1：打开时间表管理
1. 运行启动器：`scripts/launcher.bat`
2. 点击"播放时间表管理"

#### 步骤2：编辑播放任务
1. 选择要编辑的任务
2. 找到"全屏"选项
3. **勾选**：使用Kiosk全屏模式
4. **不勾选**：使用App模式（按display_config大小）
5. 保存

#### 步骤3：配置窗口大小（仅App模式需要）
如果不勾选全屏，需要配置窗口大小：
1. 点击"显示器配置"
2. 选择"自定义模式"
3. 设置窗口位置和大小
4. 保存

### 方法2：手动编辑配置文件

#### schedule.json
```json
{
  "schedules": [
    {
      "name": "CCTV13直播",
      "type": "web",
      "url": "https://tv.cctv.com/live/cctv13/",
      "fullscreen": true,  // true=Kiosk全屏, false=App模式
      "start_time": "08:00",
      "end_time": "18:00"
    }
  ]
}
```

#### display_config.json（仅App模式需要）
```json
{
  "display_mode": "custom",
  "window_geometry": {
    "x": 100,
    "y": 100,
    "width": 1304,
    "height": 742
  }
}
```

## 两种模式对比

### Kiosk全屏模式（fullscreen: true）

#### 特点
- ✅ 完全全屏，占满整个屏幕
- ✅ 完全隐藏浏览器UI（无地址栏、工具栏、标签页）
- ✅ 无窗口边框
- ✅ 无系统按钮（最小化、关闭等）
- ❌ 无法自定义窗口大小
- ❌ 无法移动窗口位置

#### 适用场景
- 固定设备的全屏播放
- 需要完全无UI的场景
- 单一显示器环境
- 不需要看到其他内容

#### 配置示例
```json
{
  "fullscreen": true,
  "url": "https://tv.cctv.com/live/cctv13/"
}
```

### App模式（fullscreen: false）

#### 特点
- ✅ 可自定义窗口大小
- ✅ 可自定义窗口位置
- ✅ 隐藏地址栏和工具栏
- ⚠️ 有窗口边框（系统边框）
- ⚠️ 有系统按钮（最小化、关闭等）
- ⚠️ 有标题栏（虽然很小）

#### 适用场景
- 需要精确控制窗口大小
- 多显示器环境
- 需要同时看到其他内容
- 窗口化播放

#### 配置示例
```json
// schedule.json
{
  "fullscreen": false,
  "url": "https://tv.cctv.com/live/cctv13/"
}

// display_config.json
{
  "display_mode": "custom",
  "window_geometry": {
    "x": 100,
    "y": 100,
    "width": 1304,
    "height": 742
  }
}
```

## 工作原理

### 代码逻辑
```python
# player.py
def _play_with_selenium(self, url, fullscreen, ...):
    # 直接使用schedule中的fullscreen参数
    self.selenium_player = SeleniumPlayerAuto(
        url=url,
        fullscreen=fullscreen,  # 来自schedule.json
        position=(x, y),        # 来自display_config.json
        size=(width, height)    # 来自display_config.json
    )
```

### Selenium启动参数
```python
# selenium_player_auto.py
if self.fullscreen:
    # Kiosk模式
    chrome_options.add_argument('--kiosk')
else:
    # App模式
    chrome_options.add_argument('--app=data:text/html,<html></html>')
    chrome_options.add_argument(f'--window-size={width},{height}')
```

## 常见问题

### Q1: 不勾选全屏，但还是全屏显示？
**原因**：display_config未配置或配置错误

**解决**：
1. 打开显示器配置
2. 选择"自定义模式"
3. 设置窗口大小
4. 保存并重启

### Q2: 勾选全屏，但窗口有边框？
**原因**：代码未更新或配置未生效

**解决**：
1. 确认schedule.json中fullscreen为true
2. 重启播放系统
3. 查看日志确认"播放参数 - 全屏: True"

### Q3: App模式下窗口大小不对？
**原因**：display_config配置错误

**解决**：
1. 检查display_config.json
2. 确认window_geometry正确
3. 运行test_custom_window.bat测试

### Q4: 想要完全无边框但不全屏？
**回答**：这是Chrome的限制，无法实现。

**选择**：
- 方案A：接受窗口边框（App模式）
- 方案B：使用全屏模式（Kiosk模式）

## 测试方法

2. 启动播放系统
3. 检查：
   - 是否占满整个屏幕
   - 是否无任何浏览器UI
   - 是否无窗口边框

### 测试App模式
1. 编辑schedule.json，设置fullscreen: false
2. 配置display_config.json
3. 启动播放系统
4. 检查：
   - 窗口大小是否正确
   - 是否无地址栏
   - 是否有窗口边框
