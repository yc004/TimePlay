# 校园闭路电视自动播放系统 - 使用手册

## 系统简介

本系统是专为校园闭路电视设计的自动定时播放系统，支持视频文件和网页直播流的定时播放，具备完善的播出安全保障机制。

## 系统要求

- Windows 7/10/11 操作系统
- Python 3.8 或更高版本
- VLC 媒体播放器
- 至少 2GB 内存
- 稳定的网络连接（用于直播流播放）

## 安装步骤

### 1. 安装 Python

从 [Python官网](https://www.python.org/downloads/) 下载并安装 Python 3.8+

安装时请勾选 "Add Python to PATH"

### 2. 安装 VLC 播放器

从 [VLC官网](https://www.videolan.org/vlc/) 下载并安装 VLC 媒体播放器

### 3. 安装系统依赖

双击运行 `install.bat` 文件，系统会自动安装所需的 Python 库

或手动执行：
```bash
pip install -r requirements.txt
```

## 快速开始

### 1. 首次使用 - 配置显示器

系统支持多显示器配置，首次使用需要配置显示位置：

#### 使用启动器（推荐）

双击运行 `launcher.bat` 打开系统启动器

点击"显示器配置"按钮进入配置界面

#### 直接配置

双击运行 `display_settings.bat` 打开显示器配置工具

#### 配置步骤

1. **查看可用显示器**：界面会显示所有连接的显示器信息
2. **选择显示模式**：
   - 全屏模式：选择一个显示器进行全屏播放
   - 自定义窗口：手动设置窗口位置和大小
3. **预览布局**：在预览区域查看显示器布局和选择效果
4. **测试显示**：点击"测试显示"按钮预览实际效果（5秒）
5. **保存配置**：确认无误后点击"保存配置"

### 2. 配置播放时间表

编辑 `schedule.json` 文件，配置播放任务：

```json
{
  "schedules": [
    {
      "id": 1,
      "name": "早间新闻",
      "time": "07:00",
      "duration": 1800,
      "type": "web",
      "url": "https://tv.cctv.com/live/cctv13/",
      "fullscreen": true,
      "topmost": true
    }
  ]
}
```

参数说明：
- `id`: 任务唯一标识
- `name`: 任务名称
- `time`: 播放时间（24小时制，格式：HH:MM）
- `duration`: 播放时长（秒）
- `type`: 内容类型（video=视频文件，web=网页直播）
- `path`: 视频文件路径（type为video时使用）
- `url`: 网页直播地址（type为web时使用）
- `fullscreen`: 是否全屏播放
- `topmost`: 是否窗口置顶

### 2. 准备视频文件

将视频文件放入 `videos` 目录

支持格式：MP4, AVI, MKV, FLV 等

### 3. 启动系统

#### 使用启动器（推荐）

双击运行 `launcher.bat` 打开系统启动器

点击"启动播放系统"按钮启动系统

#### 直接启动

双击运行 `start.bat` 启动播放系统

系统将按照时间表自动播放内容

## 多显示器配置

### 显示模式

#### 全屏模式
- 在指定的显示器上全屏播放
- 适合单一显示器输出场景
- 自动使用显示器的完整分辨率

#### 自定义窗口模式
- 手动设置窗口的位置和大小
- 适合多显示器拼接或特殊布局
- 可以跨越多个显示器

### 多显示器场景示例

#### 场景1：双显示器，主显示器播放
```
显示器1 (主): 1920x1080, 位置(0, 0)
显示器2: 1920x1080, 位置(1920, 0)

配置：
- 模式：全屏模式
- 选择：显示器1
```

#### 场景2：双显示器，副显示器播放
```
显示器1 (主): 1920x1080, 位置(0, 0)
显示器2: 1920x1080, 位置(1920, 0)

配置：
- 模式：全屏模式
- 选择：显示器2
```

#### 场景3：双显示器拼接，横跨播放
```
显示器1: 1920x1080, 位置(0, 0)
显示器2: 1920x1080, 位置(1920, 0)

配置：
- 模式：自定义窗口
- X: 0
- Y: 0
- 宽度: 3840 (两个显示器宽度之和)
- 高度: 1080
```

#### 场景4：四显示器2x2拼接
```
显示器1: 1920x1080, 位置(0, 0)
显示器2: 1920x1080, 位置(1920, 0)
显示器3: 1920x1080, 位置(0, 1080)
显示器4: 1920x1080, 位置(1920, 1080)

配置：
- 模式：自定义窗口
- X: 0
- Y: 0
- 宽度: 3840
- 高度: 2160
```

### 显示配置文件

配置保存在 `display_config.json` 文件中：

```json
{
  "display_mode": "fullscreen",
  "screen_index": 0,
  "window_geometry": {
    "x": 0,
    "y": 0,
    "width": 1920,
    "height": 1080
  }
}
```

### 测试显示功能

在保存配置前，建议使用"测试显示"功能：

1. 点击"测试显示"按钮
2. 系统会在配置的位置显示测试窗口
3. 测试窗口显示配置信息
4. 5秒后自动关闭
5. 确认位置和大小正确后再保存

## 高级功能

### 1. 开机自启动

运行 `python auto_start.py` 配置开机自启动

选择选项 1 添加到开机自启动

### 2. 远程控制

系统提供 HTTP API 接口用于远程控制：

- 获取状态: `GET http://主机IP:5000/api/status`
- 获取时间表: `GET http://主机IP:5000/api/schedules`
- 紧急插播: `POST http://主机IP:5000/api/emergency`
- 停止播放: `POST http://主机IP:5000/api/stop`
- 重新加载: `POST http://主机IP:5000/api/reload`

紧急插播示例：
```bash
curl -X POST http://主机IP:5000/api/emergency \
  -H "Content-Type: application/json" \
  -d '{
    "type": "video",
    "path": "videos/emergency.mp4",
    "duration": 60,
    "message": "紧急通知"
  }'
```

### 3. 播出安全保障

系统内置看门狗机制，自动监控播放状态：

- 心跳检测：定期检查系统运行状态
- 异常恢复：播放异常时自动恢复
- 备用内容：网络故障时播放本地备用内容

配置文件：`config.py`

```python
SAFETY_CONFIG = {
    'enable_watchdog': True,  # 启用看门狗
    'check_interval': 60,  # 检查间隔(秒)
    'backup_content': 'videos/default.mp4',  # 备用内容
    'enable_heartbeat': True  # 启用心跳检测
}
```

## 常见问题

### Q1: 视频无法播放

A: 请确认：
1. VLC 播放器已正确安装
2. 视频文件路径正确
3. 视频格式受支持

### Q2: 网页直播无法播放

A: 请确认：
1. 网络连接正常
2. 直播URL正确且可访问
3. PyQtWebEngine 已安装

### Q3: 定时任务不执行

A: 请确认：
1. 系统时间正确
2. schedule.json 格式正确
3. 查看日志文件排查错误

### Q4: 窗口无法置顶

A: 某些情况下 Windows 安全策略可能阻止窗口置顶，请以管理员权限运行

### Q5: 多显示器配置不生效

A: 请确认：
1. 显示配置已保存
2. 系统已重启
3. 显示器连接正常
4. 显示器索引正确

### Q6: 如何在特定显示器上播放

A: 
1. 运行 `display_settings.bat`
2. 选择"全屏模式"
3. 在下拉列表中选择目标显示器
4. 点击"测试显示"确认
5. 保存配置并重启系统

### Q7: 如何实现多显示器拼接播放

A:
1. 运行 `display_settings.bat`
2. 选择"自定义窗口"模式
3. 设置窗口位置为第一个显示器的位置
4. 设置窗口大小为所有显示器的总大小
5. 测试并保存配置
