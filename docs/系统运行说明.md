# 系统运行说明

## 启动方式

### 通过启动器启动（推荐）

1. 运行 `scripts/launcher.bat` 或直接运行 `src/ui/launcher.py`
2. 点击"启动播放系统"按钮
3. 系统会在后台运行，不显示控制台窗口

### 系统运行状态

- 播放系统在后台运行
- 空闲时显示黑屏窗口（带时钟）
- 有播放任务时自动切换到播放内容
- 看门狗自动监控播放状态

## 看门狗功能

### 看门狗的作用

看门狗会自动监控播放状态，在以下情况下自动恢复：

1. **播放窗口被意外关闭**
   - 检测到有任务但没有播放活动
   - 自动重新启动播放任务

2. **播放器崩溃**
   - 检测到播放器进程异常
   - 自动重启播放器

3. **系统心跳异常**
   - 检测到主循环卡死
   - 尝试恢复系统

### 看门狗的限制

看门狗运行在播放系统进程内部，因此：

- ✅ 可以恢复：播放窗口被关闭
- ✅ 可以恢复：播放器崩溃
- ✅ 可以恢复：播放内容错误
- ❌ 无法恢复：整个进程被终止（如关闭控制台窗口）

### 为什么关闭控制台窗口会终止系统？

如果启动时出现控制台窗口，关闭该窗口会：
1. 终止整个 Python 进程
2. 看门狗也随之终止（在同一进程中）
3. 无法自动恢复

**解决方案**：启动器已配置为隐藏控制台窗口，避免用户误关闭。

## 停止系统

### 正确的停止方式

1. 在启动器中点击"停止播放系统"按钮
2. 系统会正常关闭所有组件：
   - 停止调度器
   - 停止看门狗
   - 关闭播放窗口
   - 清理资源

### 不推荐的停止方式

- ❌ 关闭控制台窗口（如果出现）
- ❌ 使用任务管理器强制结束进程
- ❌ 直接关闭播放窗口

这些方式可能导致：
- 资源未正确释放
- 浏览器进程残留
- 配置未保存

## 故障排除

### 问题1：启动后出现控制台窗口

**原因**：
- 系统未找到 `pythonw.exe`
- 或启动参数未正确设置

**解决方法**：
1. 确认 Python 安装完整（包含 pythonw.exe）
2. 重新安装 Python 时选择"Add to PATH"
3. 或手动编辑启动器代码指定 pythonw.exe 路径

### 问题2：看门狗没有恢复播放

**可能原因**：
1. 看门狗未启用
2. 当前没有播放任务
3. 检查间隔太长

**检查方法**：
1. 查看日志文件 `logs/tv_system_*.log`
2. 搜索"检测到播放异常"
3. 搜索"系统恢复完成"

**配置调整**：
编辑 `config/config.py`：
```python
SAFETY_CONFIG = {
    'enable_watchdog': True,    # 确保为 True
    'check_interval': 30,       # 检查间隔（秒），可以调小
    'enable_heartbeat': True,   # 心跳检查
}
```

### 问题3：系统启动后卡死

**原因**：
- Qt 线程安全问题已修复
- 如果仍然卡死，可能是其他原因

**解决方法**：
1. 查看日志文件最后几行
2. 确认卡在哪个步骤
3. 检查该步骤的相关配置

### 问题4：ChromeDriver 版本不匹配

**现象**：
- 启动网页直播时报错
- 错误信息包含版本号

**解决方法**：
1. 打开 ChromeDriver 配置界面：`scripts\chromedriver_config.bat`
2. 点击"检测 Chrome 版本"和"检测 ChromeDriver 版本"
3. 如果版本不匹配：
   - 运行 `python install_chromedriver.py` 自动安装
   - 或手动下载匹配版本并配置路径
4. 点击"测试连接"验证配置

### 问题5：找不到 ChromeDriver

**现象**：
- 错误信息：`'chromedriver' executable needs to be in PATH`

**解决方法**：
1. 运行 `python install_chromedriver.py` 自动安装
2. 或打开 ChromeDriver 配置界面手动指定路径
3. 或将 ChromeDriver 添加到系统 PATH

## 配置文件

### 主要配置文件

1. `config/display_config.json` - 显示器配置
2. `config/schedule.json` - 播放时间表
3. `config/config.py` - 系统配置（看门狗等）
4. `config/ui_config.json` - 界面配置

### 备份建议

定期备份配置文件，特别是：
- `schedule.json` - 包含所有播放任务
- `display_config.json` - 显示器设置

## 开机自启动

### 设置方法

1. 在启动器中点击"开机自启动设置"
2. 或运行 `src/utils/auto_start.py`
3. 按提示配置

### 注意事项

- 确保配置文件路径正确
- 确保 Python 环境变量已设置
- 建议使用绝对路径

## 性能优化

### 减少资源占用

1. **调整检查间隔**
   - 增大 `check_interval` 减少 CPU 占用
   - 但会延长异常检测时间

2. **禁用不需要的功能**
   - 如果不需要看门狗，设置 `enable_watchdog: False`
   - 如果不需要空闲窗口，启动时设置 `show_idle_window=False`

3. **优化播放内容**
   - 使用合适的视频分辨率
   - 避免过大的图片文件
