# 直播流配置说明

## 问题说明

网页直播可能遇到以下问题：
1. 浏览器不支持某些视频格式
2. 网页需要用户交互才能播放
3. 网页加载慢或有广告

## 解决方案

### 方案1：使用直播流地址（推荐）

直接使用 m3u8、flv 等直播流地址，系统会自动使用 VLC 播放器播放。

#### 优点
- 播放稳定
- 无广告
- 启动快
- 资源占用少

#### 如何获取直播流地址

1. **使用在线工具**
   - 访问直播源分享网站
   - 搜索"CCTV直播源"、"电视直播源"等关键词

2. **使用浏览器开发者工具**
   - 打开直播网页
   - 按 F12 打开开发者工具
   - 切换到 Network（网络）标签
   - 播放视频
   - 筛选 m3u8 或 flv 文件
   - 复制文件URL

3. **常见直播流格式**
   - HLS: `.m3u8`
   - FLV: `.flv`
   - RTMP: `rtmp://`
   - HTTP-FLV: `http://xxx.flv`

#### 配置示例

```json
{
  "id": 1,
  "name": "CCTV13新闻",
  "start_time": "07:00",
  "end_time": "07:30",
  "weekdays": [1, 2, 3, 4, 5],
  "type": "web",
  "url": "http://your-stream-server.com/cctv13.m3u8",
  "fullscreen": true,
  "topmost": true,
  "enabled": true
}
```

### 方案2：使用网页版（备选）

如果无法获取直播流地址，可以使用网页版，但需要注意：

#### 配置要求
- 确保网络连接稳定
- 网页需要支持自动播放
- 可能需要手动点击播放按钮

#### 改进的网页播放

系统已经配置了以下优化：
- 设置了现代浏览器 User-Agent
- 启用了自动播放（无需用户手势）
- 启用了 JavaScript 和插件
- 允许不安全内容（某些直播网站需要）

#### 配置示例

```json
{
  "id": 1,
  "name": "CCTV13新闻网页版",
  "start_time": "07:00",
  "end_time": "07:30",
  "weekdays": [1, 2, 3, 4, 5],
  "type": "web",
  "url": "https://tv.cctv.com/live/cctv13/",
  "fullscreen": true,
  "topmost": true,
  "enabled": true
}
```

### 方案3：使用本地录制视频

如果直播不稳定，可以：
1. 提前录制直播内容
2. 保存为视频文件
3. 使用视频播放方式

#### 优点
- 最稳定
- 不依赖网络
- 可以精确控制内容

#### 配置示例

```json
{
  "id": 1,
  "name": "新闻录播",
  "start_time": "07:00",
  "end_time": "07:30",
  "weekdays": [1, 2, 3, 4, 5],
  "type": "video",
  "path": "videos/morning_news.mp4",
  "fullscreen": true,
  "topmost": true,
  "enabled": true
}
```

## 推荐的直播源

### CCTV频道

由于版权和技术原因，直播流地址经常变化，建议：

1. 搜索"CCTV直播源 m3u8"获取最新地址
2. 使用第三方直播源聚合服务
3. 联系当地有线电视运营商获取IPTV直播源

### 测试直播流

使用 VLC 播放器测试直播流是否可用：
1. 打开 VLC 播放器
2. 媒体 -> 打开网络串流
3. 输入直播流URL
4. 点击播放
5. 如果能正常播放，说明地址可用

## 常见问题

### Q: 网页直播提示不支持视频播放

A: 
1. 尝试获取直播流地址（m3u8）
2. 检查网络连接
3. 尝试其他直播源

### Q: 直播流无法播放

A:
1. 使用 VLC 播放器测试地址是否有效
2. 检查防火墙设置
3. 尝试其他直播源
4. 联系直播源提供方

### Q: 播放卡顿

A:
1. 检查网络带宽
2. 降低视频质量
3. 使用有线网络代替WiFi
4. 考虑使用本地录制视频

### Q: 如何找到稳定的直播源

A:
1. 使用官方IPTV服务
2. 联系当地广电部门
3. 使用付费直播服务
4. 搜索直播源分享社区
