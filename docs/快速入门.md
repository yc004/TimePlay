# 快速入门指南

## 第一步：安装系统

1. 双击运行 `install.bat`
2. 等待依赖包安装完成
3. 手动下载安装 VLC 播放器：https://www.videolan.org/vlc/

## 第二步：配置显示器

### 使用启动器（推荐）

1. 双击运行 `launcher.bat`
2. 点击"显示器配置"按钮
3. 按照界面提示配置显示器
4. 点击"测试显示"预览效果
5. 确认无误后点击"保存配置"

### 常见配置场景

#### 单显示器全屏播放
- 显示模式：选择"全屏模式"
- 选择显示器：选择"显示器1"
- 保存配置

#### 双显示器，在第二个显示器播放
- 显示模式：选择"全屏模式"
- 选择显示器：选择"显示器2"
- 保存配置

#### 多显示器拼接
- 显示模式：选择"自定义窗口"
- 设置位置：X=0, Y=0
- 设置大小：宽度=所有显示器宽度之和，高度=显示器高度
- 保存配置

## 第三步：配置播放时间表

### 使用启动器

1. 在启动器中点击"播放时间表管理"
2. 点击"添加任务"创建新任务

### 配置任务

#### 基本信息
- 任务名称：例如"早间新闻"
- 开始时间：例如 07:00
- 结束时间：例如 07:30

#### 播放星期
- 点击"选择..."按钮
- 勾选需要播放的星期
- 或使用快捷按钮：工作日、周末、全选

#### 内容类型

##### 播放单个视频
1. 类型：选择"video"
2. 点击"浏览..."选择视频文件
3. 勾选"全屏播放"和"窗口置顶"
4. 勾选"启用此任务"

##### 播放网页直播
1. 类型：选择"web"
2. 输入直播URL，例如：https://tv.cctv.com/live/cctv13/
3. 勾选"全屏播放"和"窗口置顶"
4. 勾选"启用此任务"

##### 轮播多个视频
1. 类型：选择"playlist"
2. 点击"编辑轮播列表..."
3. 在轮播编辑器中：
   - 点击"添加视频"选择视频文件
   - 设置每个视频的播放时长（秒）
   - 可以添加多个视频
   - 使用"上移"/"下移"调整播放顺序
4. 勾选"循环播放轮播列表"
5. 点击"确定"保存轮播列表
6. 勾选"启用此任务"

### 保存配置

点击"保存配置"按钮保存时间表

## 第四步：启动系统

### 使用启动器

1. 在启动器中点击"启动播放系统"
2. 系统开始运行，等待定时任务执行

### 直接启动

双击运行 `start.bat`

## 第五步：测试播放

### 测试单个视频

1. 在启动器中点击"播放器测试"
2. 选择"1. 测试视频播放"
3. 输入视频文件路径
4. 观察播放效果

### 测试网页直播

1. 在启动器中点击"播放器测试"
2. 选择"2. 测试网页直播流"
3. 输入直播URL
4. 观察播放效果

## 配置示例

### 示例1：工作日早间新闻

```
任务名称：早间新闻
开始时间：07:00
结束时间：07:30
播放星期：一、二、三、四、五
内容类型：web
网页URL：https://tv.cctv.com/live/cctv13/
全屏播放：是
窗口置顶：是
启用任务：是
```

### 示例2：课间轮播宣传片

```
任务名称：课间轮播
开始时间：10:00

播放星期：一、二、三、四、五

  - 视频2：videos/safety_tips.mp4 (300秒)

```

## 开机自启动（可选）

### 配置自启动

1. 在启动器中点击"开机自启动设置"
2. 选择"1. 添加到开机自启动"
3. 按回车确认

### 取消自启动

1. 在启动器中点击"开机自启动设置"
2. 选择"2. 从开机自启动移除"
3. 按回车确认

## 常用操作

### 修改播放时间表

1. 打开启动器
2. 点击"播放时间表管理"
3. 选择要修改的任务
4. 点击"编辑任务"
5. 修改后点击"确定"
6. 点击"保存配置"

### 临时禁用某个任务

1. 打开播放时间表管理
2. 选择要禁用的任务
3. 点击"编辑任务"
4. 取消勾选"启用此任务"
5. 点击"确定"
6. 点击"保存配置"

### 更改显示器

1. 打开启动器
2. 点击"显示器配置"
3. 选择新的显示器或调整窗口位置
4. 测试并保存
5. 重启播放系统

### 紧急停止播放

1. 打开启动器
2. 点击"停止播放系统"

或者直接关闭播放窗口（如果可以访问）

## 故障排除

### 系统无法启动

1. 检查Python是否正确安装
2. 检查依赖包是否安装完成
3. 查看logs目录下的日志文件

### 视频无法播放

1. 检查VLC播放器是否安装
2. 检查视频文件路径是否正确
3. 检查视频格式是否支持

### 网页直播无法播放

1. 检查网络连接
2. 检查URL是否正确
3. 尝试在浏览器中打开URL测试

### 定时任务不执行

1. 检查系统时间是否正确
2. 检查任务是否启用
3. 检查星期配置是否包含当天
4. 检查时间段是否正确

### 显示位置不正确

1. 重新打开显示器配置
2. 使用"测试显示"功能确认
3. 检查显示器连接是否正常
4. 重启系统
