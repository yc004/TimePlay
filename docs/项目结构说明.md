# 项目结构说明

## 目录结构

### 根目录文件
- `main.py` - 主程序入口
- `run.py` - 启动脚本（处理导入路径）
- `requirements.txt` - Python依赖列表
- `README.md` - 项目说明文档

### src/ - 源代码目录

#### src/core/ - 核心功能模块
- `player.py` - 媒体播放器，支持视频和直播流播放
- `scheduler.py` - 任务调度器，管理定时播放任务
- `watchdog.py` - 播出安全看门狗，监控播放状态
- `browser_player.py` - 浏览器播放器，用于播放网页直播
- `web_player.py` - 增强的网页播放器
- `stream_extractor.py` - 视频流提取器
- `emergency_broadcast.py` - 紧急插播功能
- `remote_control.py` - 远程控制服务器

#### src/ui/ - 用户界面模块
- `launcher.py` - 系统启动器，集成所有功能的入口
- `gui_manager.py` - 播放时间表管理界面
- `display_settings_ui.py` - 显示器配置界面
- `playlist_editor.py` - 轮播列表编辑器

#### src/utils/ - 工具模块
- `logger.py` - 日志记录工具
- `display_config.py` - 显示配置管理
- `auto_start.py` - 开机自启动配置

### config/ - 配置文件目录
- `schedule.json` - 播放时间表配置
- `display_config.json` - 显示器配置
- `live_streams.json` - 直播源配置示例

### docs/ - 文档目录
- `使用手册.md` - 完整的使用手册
- `快速入门.md` - 快速入门指南
- `配置说明.md` - 配置文件详细说明
- `stream_helper.md` - 直播流配置帮助
- `live_stream_guide.txt` - 直播配置指南
- `项目结构说明.md` - 本文档

### scripts/ - 启动脚本目录
- `start.bat` - 启动播放系统
- `launcher.bat` - 启动系统启动器
- `manager.bat` - 启动时间表管理界面
- `display_settings.bat` - 启动显示设置界面
- `install.bat` - 安装系统依赖
- `test_*.bat` - 各种测试工具

### tests/ - 测试文件目录
- `test_player.py` - 播放器测试
- `test_display.py` - 显示配置测试
- `test_stream_extractor.py` - 流提取器测试

### 其他目录
- `videos/` - 视频文件存放目录
- `logs/` - 系统日志文件目录

## 模块依赖关系

```
main.py
  ├── src.core.player
  │   ├── src.core.browser_player
  │   ├── src.utils.display_config
  │   └── src.utils.logger
  ├── src.core.scheduler
  │   ├── src.core.player
  │   └── src.utils.logger
  └── src.core.watchdog
      ├── src.core.player
      ├── src.core.scheduler
      └── src.utils.logger
```

## 启动流程

1. 用户运行 `scripts/start.bat`
2. 脚本切换到项目根目录
3. 执行 `python run.py`
4. `run.py` 设置Python路径
5. 导入并执行 `main.py`
6. `main.py` 初始化各个模块
7. 系统开始运行

## 配置文件位置

所有配置文件统一放在 `config/` 目录：
- 播放时间表：`config/schedule.json`
- 显示配置：`config/display_config.json`
- 直播源：`config/live_streams.json`

## 日志文件位置

日志文件自动保存在 `logs/` 目录：
- 格式：`tv_system_YYYYMMDD.log`
- 每天一个日志文件
- 包含所有系统运行信息

## 开发说明

### 添加新功能模块

1. 在 `src/core/` 或 `src/ui/` 创建新的Python文件
2. 在文件中导入需要的模块：
   ```python
   from utils.logger import Logger
   from utils.display_config import DisplayConfig
   ```
3. 在 `main.py` 或相应的启动文件中导入新模块

### 修改配置

1. 编辑 `config/` 目录下的JSON文件
2. 或使用图形界面工具修改
3. 重启系统使配置生效

### 调试

1. 查看 `logs/` 目录下的日志文件
2. 使用测试工具验证功能
3. 在代码中添加日志输出

## 注意事项

1. 不要直接修改 `src/` 目录下的 `__init__.py` 文件
2. 配置文件使用UTF-8编码
3. 日志文件会自动创建，无需手动创建
4. 视频文件建议放在 `videos/` 目录
