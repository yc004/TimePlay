# 全屏功能快速参考

## 问题：浏览器全屏了但视频没有全屏

### 解决方案 ✅

系统已经实现了完整的解决方案，包括：

1. **Kiosk模式** - 浏览器窗口全屏（无边框）
2. **CSS强制全屏** - 播放器元素全屏（占满屏幕）
3. **隐藏其他元素** - 只显示视频内容

### 工作原理

```
启动 → 加载页面 → 3秒后尝试API全屏 → 4秒后CSS强制全屏 ⭐
```

CSS强制全屏会：
- 将播放器设置为 `position: fixed`
- 设置尺寸为 `100vw x 100vh`
- 隐藏页面其他元素（导航栏、侧边栏等）
- 保持视频比例 `object-fit: contain`

## 如果还是不全屏

### 检查步骤

1. 打开浏览器开发者工具（F12）
2. 查看Console标签
3. 查找以下日志：

```
=== 自动播放和全屏脚本开始 ===
找到 X 个视频元素
尝试强制播放器全屏...
找到播放器: [选择器]
✓ 播放器全屏已应用
```

### 如果没有找到播放器

可能需要添加特定网站的选择器：

```javascript
// 在 forcePlayerFullscreen() 函数中
var playerSelectors = [
    '.player',
    '.video-player',
    '[class*="player"]',
    '[id*="player"]',
    'video',
    // 添加你的网站特定选择器
    '.your-site-player-class'
];
```

## 调试技巧

### 1. 查看页面结构

在浏览器控制台执行：
```javascript
// 查找所有可能的播放器元素
document.querySelectorAll('[class*="player"]')
document.querySelectorAll('[id*="player"]')
document.querySelectorAll('video')
```

### 2. 手动测试CSS全屏

在浏览器控制台执行：
```javascript
var player = document.querySelector('video');
player.style.position = 'fixed';
player.style.top = '0';
player.style.left = '0';
player.style.width = '100vw';
player.style.height = '100vh';
player.style.zIndex = '999999';
```

### 3. 检查是否被其他元素遮挡

```javascript
// 查看z-index最高的元素
Array.from(document.querySelectorAll('*'))
  .map(el => ({el, z: window.getComputedStyle(el).zIndex}))
  .filter(({z}) => z !== 'auto')
  .sort((a, b) => b.z - a.z)
  .slice(0, 10)
```

## 配置选项

### 禁用Kiosk模式

如果需要保留浏览器控制：

```python
# 在 src/core/selenium_player_auto.py 第64-65行
if self.fullscreen:
    chrome_options.add_argument('--start-fullscreen')
    # chrome_options.add_argument('--kiosk')  # 注释掉这行
```

