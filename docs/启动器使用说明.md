# 启动器使用说明

## 问题：点击"启动播放系统"后没有显示窗口

### 原因

启动器使用独立进程启动播放系统，新进程的窗口可能不会自动显示到前台。

### 解决方案

已修改启动器，使用更好的启动方式：

1. 使用 `subprocess.Popen` 而不是 `QProcess`
2. 在Windows上使用 `CREATE_NEW_CONSOLE` 标志
3. 启动 `start_with_selenium.py` 而不是 `run.py`

## 启动方式对比

### 方式1: 通过启动器（图形界面）

```bash
scripts\launcher.bat
```

**优点：**
- 图形界面，易于使用
- 可以管理配置
- 可以启动/停止系统

**注意：**
- 点击"启动播放系统"后，会打开新的控制台窗口
- 空闲窗口会在新窗口中显示
- 不要关闭控制台窗口

### 方式2: 直接启动（推荐）⭐

```bash
start_direct.bat
```

或

```bash
start_selenium.bat
```

**优点：**
- 直接启动，窗口立即显示
- 更可靠
- 适合日常使用

**推荐用于：**
- 日常播放
- 开机自启动
- 无人值守运行

### 方式3: 命令行启动

```bash
python start_with_selenium.py
```

**优点：**
- 可以看到详细日志
- 便于调试

## 使用步骤

### 首次使用

1. **配置显示器**


   ```bash
   scripts\launcher.bat

   ```

3. **启动系统**
   ```bash
   start_direct.bat
   ```

### 日常使用

**推荐方式：**
```bash
start_direct.bat
```

或通过启动器：
```bash
scripts\launcher.bat
# 点击"启动播放系统"
```

## 窗口显示说明

### 启动后应该看到

1. **控制台窗口**（如果使用批处理启动）
   - 显示系统日志
   - 不要关闭此窗口

2. **空闲窗口**（黑屏+时钟）
   - 全屏黑色背景
   - 显示当前时间
   - 表示系统正在运行

3. **播放窗口**（有任务时）
   - 自动替换空闲窗口
   - 显示播放内容
   - 任务结束后恢复空闲窗口

### 如果看不到窗口

1. **检查任务栏**
   - 查看是否有窗口图标
   - 点击图标切换到窗口

2. **按 Alt+Tab**
   - 查看所有打开的窗口
   - 找到"校园闭路电视播放系统"

3. **检查其他显示器**
   - 如果有多个显示器
   - 窗口可能在其他显示器上

4. **查看日志**
   - 打开 `logs/tv_system_YYYYMMDD.log`
   - 查找"空闲窗口已显示"

## 停止系统

### 通过启动器

```bash
scripts\launcher.bat
# 点击"停止播放系统"
```

### 直接关闭

- 关闭控制台窗口
- 或按 Ctrl+C

## 故障排除

### 问题1: 点击启动后没反应

**检查：**
1. 是否已经启动（检查任务管理器）
2. 是否有错误提示
3. 查看日志文件

**解决：**
- 使用 `start_direct.bat` 直接启动
- 或使用命令行查看错误信息

### 问题2: 窗口一闪而过

**原因：** 程序出错退出

**解决：**
1. 使用命令行启动查看错误
   ```bash
   python start_with_selenium.py
   ```
2. 查看日志文件
3. 检查配置文件是否正确

### 问题3: 多个窗口同时显示

**原因：** 多次点击启动按钮

**解决：**
1. 停止所有实例
2. 重新启动一次

### 问题4: 无法停止系统

**解决：**
1. 通过任务管理器结束进程
2. 查找 `python.exe` 进程
3. 结束相关进程

## 开机自启动

### 设置方法

1. 通过启动器设置
   ```bash
   scripts\launcher.bat
   # 点击"开机自启动设置"
   ```

2. 手动设置
   - 创建快捷方式到 `start_direct.bat`
   - 放到启动文件夹

### 启动文件夹位置

```
C:\Users\[用户名]\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup
```

或按 `Win+R`，输入 `shell:startup`
