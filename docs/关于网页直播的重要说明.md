# 关于网页直播白屏问题的重要说明

## 问题描述

使用浏览器播放器播放网页直播时，可能会出现以下情况：
- 窗口显示纯白色，没有视频内容
- 页面似乎在加载，但始终不显示视频
- 日志显示"页面加载完成"，但看不到画面

## 根本原因

网页直播的白屏问题主要由以下原因造成：

### 1. 视频加密和DRM保护
许多直播网站（包括央视等）使用了视频加密技术：
- 视频流经过加密处理
- 需要特定的解密密钥
- 只能在特定的浏览器环境中播放
- 嵌入式浏览器（QWebEngineView）可能无法获取解密密钥

### 2. 用户交互要求
现代浏览器的自动播放策略：
- 浏览器默认禁止自动播放有声音的视频
- 需要用户交互（点击）才能播放
- 虽然我们的脚本会尝试自动点击，但不是100%成功

### 3. 页面结构复杂
直播网站的页面结构：
- 使用iframe嵌套
- 动态加载视频元素
- 使用特殊的播放器框架
- JavaScript代码可能检测运行环境

### 4. 网络和权限问题
- 某些直播源有地域限制
- 需要特定的Cookie或Token
- 网络连接不稳定

## 解决方案

### 方案1：使用直接流URL（强烈推荐）⭐

这是最可靠的方案，绕过网页直接播放视频流。

**步骤：**

1. 获取m3u8直播流地址
   - 搜索"CCTV直播源 m3u8"
   - 使用浏览器开发者工具抓取
   - 联系IPTV服务提供商

2. 在VLC中测试
   ```
   打开VLC -> 媒体 -> 打开网络串流 -> 输入URL
   ```

3. 配置到schedule.json
   ```json
   {
     "name": "央视新闻",
     "type": "web",
     "url": "http://your-server.com/cctv13.m3u8",
     "start_time": "07:00",
     "end_time": "07:30"
   }
   ```

**优点：**
- ✅ 播放稳定可靠
- ✅ 自动播放，无需交互
- ✅ 资源占用少
- ✅ 无广告干扰
- ✅ 不会出现白屏

### 方案2：使用录制的视频文件（最稳定）⭐⭐

提前录制新闻节目，保存为视频文件。

**步骤：**

1. 录制视频
   - 使用录屏软件录制直播
   - 或下载新闻视频
   - 保存为MP4格式

2. 放到videos目录
   ```
   videos/morning_news.mp4
   videos/evening_news.mp4
   ```

3. 配置到schedule.json
   ```json
   {
     "name": "早间新闻",
     "type": "video",
     "path": "videos/morning_news.mp4",
     "start_time": "07:00",
     "end_time": "07:30"
   }
   ```

**优点：**
- ✅ 最稳定，100%可靠
- ✅ 不依赖网络
- ✅ 可精确控制内容
- ✅ 可反复使用
- ✅ 绝不会出现白屏

### 方案3：优化网页播放（不推荐）

如果必须使用网页版，可以尝试以下优化：

**A. 尝试不同的直播源**
```
CCTV13: https://tv.cctv.com/live/cctv13/
CCTV1:  https://tv.cctv.com/live/cctv1/
```

**B. 使用移动版页面**
移动版页面通常更简单，更容易自动播放：
```
https://tv.cctv.com/live/cctv13/m/
```

**C. 增加加载等待时间**
修改 `src/core/browser_player.py`，增加等待时间：
```python
self.auto_play_timer.start(5000)  # 从3秒改为5秒
```

**D. 手动交互**
- 在播放开始时，手动点击播放按钮
- 适合测试环境，不适合自动化

### 方案4：混合方案（推荐）⭐

结合多种方案，提供最佳体验：

```json
{
  "schedules": [
    {
      "name": "早间新闻（直播流）",
      "type": "web",
      "url": "http://stream-server.com/cctv13.m3u8",
      "start_time": "07:00",
      "end_time": "07:30",
      "enabled": true
    },
    {
      "name": "早间新闻（备用视频）",
      "type": "video",
      "path": "videos/morning_news_backup.mp4",
      "start_time": "07:00",
      "end_time": "07:30",
      "enabled": false,
      "注释": "当直播失败时，手动启用此项"
    }
  ]
}
```

## 技术细节

### 为什么不能简单提取视频URL？

很多人会想：为什么不直接提取网页中的视频URL？

**原因：**
1. 视频URL是加密的
2. URL包含时效性Token
3. 需要特定的HTTP头
4. 可能需要Cookie认证
5. 视频流是分段的（HLS/DASH）

### 浏览器播放器的工作原理

我们的浏览器播放器：
1. 使用QWebEngineView加载网页
2. 配置浏览器设置（允许自动播放等）
3. 注入JavaScript脚本
4. 自动查找视频元素
5. 尝试自动播放
6. 模拟点击播放按钮

但是，这个方案有局限性：
- 不是所有网站都支持
- 可能被网站检测和阻止
- 依赖网站的页面结构
- 网站更新可能导致失效

### 为什么推荐使用直播流？

直播流（m3u8）的优势：
- 标准化的协议
- VLC等播放器原生支持
- 不需要浏览器
- 播放稳定可靠
- 资源占用少
- 易于管理和维护

## 常见问题

### Q: 我找不到m3u8直播源怎么办？
A: 
1. 搜索"CCTV直播源"、"电视直播源"
2. 访问GitHub上的直播源项目
3. 联系当地广电部门
4. 使用录制的视频文件代替

### Q: 测试工具也是白屏怎么办？
A: 
1. 检查网络连接
2. 在普通浏览器中测试URL
3. 查看日志文件中的错误
4. 尝试其他直播源
5. 考虑使用方案1或方案2

### Q: 可以使用YouTube等国外直播吗？
A: 
理论上可以，但：
1. 需要稳定的国际网络
2. 可能有地域限制
3. 建议使用国内直播源

### Q: 如何获取直播流的m3u8地址？
A: 
1. 打开浏览器开发者工具（F12）
2. 切换到Network标签
3. 播放直播
4. 搜索".m3u8"
5. 复制URL
6. 在VLC中测试
