# 播放列表功能说明

## 概述

系统现在统一使用播放列表（playlist）方式管理所有播放任务。播放列表支持视频、图片和网页直播的混合播放，并提供自动时长检测和自定义时长功能。

## 主要特性

- ✅ 统一的播放列表格式
- ✅ 自动检测视频时长
- ✅ 支持图片播放（可配置显示时长）
- ✅ 支持视频、图片、网页直播混合播放
- ✅ 自动媒体类型识别
- ✅ 灵活的时长配置

## 配置格式

### 基本结构

```json
{
  "schedules": [
    {
      "name": "任务名称",
      "start_time": "08:00",
      "end_time": "18:00",
      "weekdays": [1, 2, 3, 4, 5, 6, 7],
      "type": "playlist",
      "fullscreen": true,
      "topmost": true,
      "enabled": true,
      "loop": true,
      "playlist": [
        // 播放项列表
      ]
    }
  ]
}
```

### 播放项类型

#### 1. 视频播放项

```json
{
  "type": "video",
  "path": "C:/Videos/sample.mp4",
  "duration": 0,
  "loop": false,
  "comment": "视频说明"
}
```

参数说明：
- `type`: 必填，值为 "video"
- `path`: 必填，视频文件路径
- `duration`: 可选，播放时长（秒）
  - 0 或不设置：自动获取视频完整时长
  - 大于0：播放指定时长后切换到下一项
- `loop`: 可选，是否循环播放（默认false）
- `comment`: 可选，备注说明

#### 2. 图片播放项

```json
{
  "type": "image",
  "path": "C:/Images/poster.jpg",
  "duration": 10,
  "comment": "图片说明"
}
```

参数说明：
- `type`: 必填，值为 "image"
- `path`: 必填，图片文件路径
- `duration`: 可选，显示时长（秒）
  - 不设置：使用默认值5秒
  - 大于0：显示指定时长
- `comment`: 可选，备注说明

支持的图片格式：
- JPG/JPEG
- PNG
- GIF
- BMP
- WEBP
- TIFF
- SVG

#### 3. 网页直播播放项

```json
{
  "type": "web",
  "url": "https://tv.cctv.com/live/cctv13/",
  "duration": 300,
  "comment": "直播说明"
}
```

参数说明：
- `type`: 必填，值为 "web"
- `url`: 必填，网页URL
- `duration`: 必填，播放时长（秒）
- `comment`: 可选，备注说明

#### 4. 自动类型检测

如果不指定 `type`，系统会自动检测：

```json
{
  "path": "C:/Videos/sample.mp4",
  "duration": 0
}
```

系统会根据文件扩展名自动识别为视频、图片或网页。

## 时长配置策略

### 视频时长

1. **不设置duration或设置为0**（推荐）
   - 系统自动获取视频完整时长
   - 播放完整视频后切换到下一项
   
2. **设置具体时长**
   - 播放指定时长后切换
   - 适合只播放视频片段的场景

3. **启用循环播放**
   - 设置 `loop: true`
   - 在指定时长内循环播放视频

### 图片时长

1. **不设置duration**
   - 使用默认值5秒
   
2. **设置具体时长**
   - 显示指定秒数
   - 建议范围：3-30秒

### 网页直播时长

- 必须设置duration
- 建议根据内容设置合理时长
- 例如：新闻5-10分钟，节目30-60分钟

## 自动功能

### 1. 视频时长自动获取

系统会自动读取视频文件的元数据获取时长：

```python
# 自动获取
{
  "type": "video",
  "path": "video.mp4"
  // duration自动设置为视频实际时长
}
```

### 2. 媒体类型自动识别

不指定type时，系统根据扩展名自动识别：

```python
# 自动识别为视频
{"path": "file.mp4"}

# 自动识别为图片
{"path": "file.jpg"}

# 自动识别为网页
{"url": "https://..."}
```

### 3. 播放列表循环

设置 `loop: true` 后，播放列表会在时间段内循环播放：

```json
{
  "loop": true,
  "playlist": [...]
  // 播放完最后一项后，自动从第一项重新开始
}
```

## 注意事项

1. **文件路径**
   - 使用绝对路径
   - Windows路径使用正斜杠 `/` 或双反斜杠 `\\`
   - 确保文件存在且可访问

2. **视频时长获取**
   - 首次获取可能需要几秒钟
   - 如果获取失败，使用默认值300秒
   - 建议手动设置时长以加快启动速度

3. **图片显示**
   - 图片会自动缩放以适应窗口
   - 保持原始宽高比
   - 背景为黑色

4. **播放列表循环**
   - 循环在时间段结束时自动停止
   - 每个播放项按顺序播放
   - 支持单个项目的循环播放

5. **性能考虑**
   - 大量图片轮播建议使用较短时长
   - 视频文件建议存储在本地磁盘
   - 网页直播需要稳定的网络连接

## 迁移指南

### 从旧格式迁移

旧格式（不再支持）：
```json
{
  "type": "video",
  "path": "video.mp4",
  ...
}
```

新格式：
```json
{
  "type": "playlist",
  "playlist": [
    {
      "type": "video",
      "path": "video.mp4"
    }
  ],
  ...
}
```

### 批量转换

单个视频任务 → 播放列表：
```json
// 旧
{
  "name": "视频播放",
  "type": "video",
  "path": "video.mp4"
}

// 新
{
  "name": "视频播放",
  "type": "playlist",
  "playlist": [
    {"type": "video", "path": "video.mp4"}
  ]
}
```

## 故障排除

### 视频时长获取失败

- 检查视频文件是否损坏
- 手动设置duration参数
- 查看日志文件了解详细错误

### 图片不显示

- 检查图片文件路径是否正确
- 确认图片格式是否支持
- 查看日志中的错误信息

### 播放列表不循环

- 确认 `loop: true` 设置正确
- 检查时间段是否正确
- 确认播放列表不为空
