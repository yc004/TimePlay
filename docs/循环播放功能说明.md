# 视频循环播放功能说明

## 功能概述

系统现在支持视频文件的循环播放功能。当启用循环播放时，视频播放结束后会自动重新开始播放，直到达到设定的播放时长或手动停止。

## 使用方法

### 1. 在时间表中配置循环播放

编辑 `config/schedule.json` 文件，在视频播放任务中添加 `loop` 参数：

```json
{
  "name": "循环播放示例",
  "start_time": "09:00",
  "end_time": "12:00",
  "weekdays": [1, 2, 3, 4, 5],
  "type": "video",
  "fullscreen": true,
  "topmost": true,
  "enabled": true,
  "path": "C:/Videos/sample.mp4",
  "loop": true,
  "id": 1
}
```

### 2. 在轮播列表中配置循环播放

在轮播列表的视频项中添加 `loop` 参数：

```json
{
  "name": "轮播示例",
  "start_time": "14:00",
  "end_time": "18:00",
  "type": "playlist",
  "fullscreen": true,
  "loop": true,
  "playlist": [
    {
      "type": "video",
      "path": "C:/Videos/video1.mp4",
      "duration": 300,
      "loop": true
    },
    {
      "type": "video",
      "path": "C:/Videos/video2.mp4",
      "duration": 600,
      "loop": false
    }
  ]
}
```

### 3. 代码中使用循环播放

```python
from src.core.player import MediaPlayer

player = MediaPlayer()

# 播放视频并启用循环
player.play_video(
    video_path="C:/Videos/sample.mp4",
    fullscreen=True,
    topmost=True,
    duration=3600,  # 播放1小时
    loop=True       # 启用循环
)
```

## 配置参数说明

### loop 参数

- **类型**: 布尔值 (true/false)
- **默认值**: false
- **说明**: 
  - `true`: 启用循环播放，视频结束后自动重新开始
  - `false`: 不循环，视频播放一次后停止

### 与 duration 参数的关系

- 如果设置了 `duration` 参数，视频会在指定时长后停止，即使启用了循环
- 如果 `duration` 为 0 或未设置，循环播放会一直持续到时间表结束时间

## 工作原理

1. 当启用循环播放时，系统会监听 VLC 播放器的 `MediaPlayerEndReached` 事件
2. 视频播放结束时，自动重新加载并播放同一视频
3. 停止播放时，自动清理事件监听器和循环状态

## 注意事项

1. 循环播放仅支持视频文件，不支持网页直播流
2. 循环播放会在以下情况下停止：
   - 达到设定的播放时长 (duration)
   - 时间表任务结束时间到达
   - 手动停止播放
   - 系统关闭
3. 短视频循环播放时，切换间隔非常短，几乎无缝衔接

## 测试方法

运行测试脚本验证循环播放功能：

```bash
# Windows
test_loop_playback.bat

# 或直接运行
python test_loop_playback.py
```

测试脚本会播放视频30秒，期间视频会循环播放。

## 故障排除

### 视频不循环播放

1. 检查 `loop` 参数是否设置为 `true`
2. 检查日志文件，确认循环播放监听已启用
3. 确认视频文件路径正确且文件可以正常播放

### 循环播放卡顿

1. 这是正常现象，视频重新加载需要短暂时间
2. 使用较短的视频文件可以减少卡顿感
3. 确保视频文件在本地磁盘，避免网络延迟
