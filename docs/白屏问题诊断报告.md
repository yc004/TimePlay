# 白屏问题诊断报告

## 问题描述
启动网页直播后，播放窗口显示纯白色，没有正常显示直播画面。
对比测试显示：原版和改进版播放器都显示白屏。

## 诊断结果

### 1. WebEngine文件检查 ✓
- 所有关键文件都存在
- QtWebEngineProcess.exe 正常
- 资源文件完整
- 可以成功导入 QtWebEngineWidgets

### 2. 根本原因
**QtWebEngine沙箱机制问题**

在某些Windows环境下，QtWebEngine的Chromium沙箱机制会导致渲染进程无法正常启动，表现为：
- 页面加载但不显示内容
- 完全白屏
- 没有JavaScript控制台输出
- 没有错误提示

### 3. 为什么两个播放器都白屏
因为问题不在播放器代码本身，而是底层的QtWebEngine渲染引擎。
无论如何改进播放器代码，只要使用QtWebEngine，都会遇到同样的问题。

## 解决方案

### 方案A: 禁用沙箱 (推荐) ⭐

#### 原理
通过环境变量禁用WebEngine的沙箱机制和GPU加速：
```python
os.environ['QTWEBENGINE_DISABLE_SANDBOX'] = '1'
os.environ['QTWEBENGINE_CHROMIUM_FLAGS'] = '--disable-gpu --no-sandbox'
```

#### 实施步骤
1. 运行测试: `python test_with_sandbox_disabled.py`
2. 如果测试成功，使用: `start_fixed.bat`

#### 优点
- 简单有效
- 不需要修改大量代码
- 兼容性好

#### 缺点
- 略微降低安全性（仅WebEngine部分）
- 禁用GPU加速（对直播影响很小）

### 方案B: 使用直播流URL (最稳定) ⭐⭐⭐

#### 原理
获取m3u8格式的直播流URL，直接使用VLC播放器，完全不依赖WebEngine。

#### 配置示例
```json
{
  "name": "CCTV13",
  "type": "stream",
  "url": "http://[直播流地址]/cctv13.m3u8"
}
```

#### 优点
- 最稳定
- 性能最好
- 无白屏问题
- 不依赖WebEngine

#### 缺点
- 需要获取直播流URL
- 某些网站不提供直接流URL

### 方案C: 其他浏览器引擎

考虑使用：
- CEFPython (Chromium Embedded Framework)
- 系统默认浏览器（全屏模式）

## 技术细节

### 为什么禁用沙箱有效?

QtWebEngine使用Chromium的多进程架构：
- 主进程: 管理界面
- 渲染进程: 渲染网页内容

沙箱机制限制渲染进程的权限，在某些Windows环境下：
- 渲染进程无法获得必要权限
- 进程启动失败或无法正常工作
- 表现为白屏

禁用沙箱后：
- 渲染进程获得正常权限
- 可以正常启动和工作
- 内容正常显示

### 安全性考虑

禁用沙箱只影响WebEngine部分：
- 主程序不受影响
- 只是播放网页内容
- 不涉及敏感操作
- 风险可控

对于内网使用的直播播放系统，这个风险可以接受。

### 性能影响

禁用GPU加速的影响：
- 2D内容: 几乎无影响
- 视频播放: 影响很小
- 3D内容: 可能有影响（但直播不需要）

实际测试表明，对直播播放的影响可以忽略不计。
