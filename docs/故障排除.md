# 故障排除指南

## 问题：运行bat脚本后立即退出

### 原因分析
1. Python未安装或未添加到PATH
2. 缺少必要的依赖包
3. 代码有语法错误或导入错误
4. 工作目录不正确

### 解决步骤

#### 步骤1：检查环境
```
双击运行: scripts\check_env.bat
```
这会检查：
- Python是否安装
- 所有依赖包是否安装
- VLC播放器是否安装
- 项目结构是否正确

#### 步骤2：测试模块导入
```
双击运行: scripts\test_imports.bat
```
这会测试所有Python模块是否能正常导入

#### 步骤3：安装依赖
如果检查发现缺少依赖：
```
双击运行: scripts\install.bat
```

#### 步骤4：查看详细错误
修改bat文件，在最后添加 `pause` 命令，这样可以看到错误信息

或者直接在命令行中运行：
```
cd C:\path\to\TimerPlay
python src\ui\launcher.py
```

## 常见错误及解决方法

### 错误1：ModuleNotFoundError: No module named 'PyQt5'
**原因**：缺少PyQt5包

**解决**：
```
pip install PyQt5 PyQtWebEngine
```

### 错误2：ModuleNotFoundError: No module named 'vlc'
**原因**：缺少python-vlc包

**解决**：
```
pip install python-vlc
```

同时确保VLC播放器已安装：
https://www.videolan.org/vlc/

### 错误3：ModuleNotFoundError: No module named 'src'
**原因**：Python路径设置问题

**解决**：确保在项目根目录运行脚本
```
cd C:\path\to\TimerPlay
python src\ui\launcher.py
```

### 错误4：FileNotFoundError: [Errno 2] No such file or directory: 'config/schedule.json'
**原因**：配置文件不存在或路径错误

**解决**：
1. 确认 config 目录存在
2. 确认 schedule.json 文件存在
3. 检查文件路径是否正确

### 错误5：窗口一闪而过
**原因**：程序遇到错误立即退出

**解决**：
1. 在命令行中运行，查看错误信息
2. 查看 logs 目录下的日志文件
3. 运行 scripts\test_imports.bat 检查导入

## 调试技巧

### 1. 使用命令行运行
不要双击bat文件，而是：
1. 按 Win+R
2. 输入 cmd
3. cd 到项目目录
4. 运行命令

这样可以看到完整的错误信息

### 2. 查看日志文件
```
logs\tv_system_YYYYMMDD.log
```
包含详细的运行日志

### 3. 逐步测试
按顺序测试：
1. `scripts\check_env.bat` - 检查环境
2. `scripts\test_imports.bat` - 测试导入
3. `scripts\launcher.bat` - 启动程序

### 4. Python版本
确保使用 Python 3.8 或更高版本：
```
python --version
```

## 问题：播放直播流时出现白屏

### 现象
使用浏览器播放器播放网页直播时，窗口显示纯白色，没有视频内容

### 诊断步骤

#### 步骤1：使用测试工具
```
双击运行: scripts\test_browser_player.bat
```
这个工具可以：
- 在独立窗口中测试浏览器播放器
- 显示详细的加载日志
- 查看JavaScript控制台消息
- 方便地重新加载和调试

#### 步骤2：检查日志
查看 `logs\tv_system_YYYYMMDD.log` 文件，寻找：
- "页面加载进度" 消息 - 确认页面是否在加载
- "页面加载完成" 消息 - 确认页面是否加载成功
- "浏览器JS" 消息 - 查看JavaScript执行情况
- 任何错误消息

#### 步骤3：常见原因及解决方法

**原因1：网络连接问题**
- 检查是否能在普通浏览器中打开直播页面
- 尝试使用其他直播URL测试

**原因2：直播页面需要用户交互**
- 某些直播网站要求用户点击才能播放
- 当前的自动播放脚本会尝试自动点击播放按钮
- 查看日志中是否有"点击播放按钮"的消息

**原因3：视频元素未找到**
- 页面可能使用iframe或特殊的视频加载方式
- 查看日志中"找到 X 个视频元素"的消息
- 如果找到0个视频元素，说明页面结构特殊

**原因4：WebEngine配置问题**
- 确保PyQtWebEngine正确安装
- 尝试重新安装：`pip install --upgrade PyQtWebEngine`

**原因5：视频加密或DRM保护**
- 某些直播流使用DRM保护，无法在嵌入式浏览器中播放
- 尝试使用其他直播源

### 解决方案

**方案1：使用测试工具调试**
```
scripts\test_browser_player.bat
```
在测试工具中：
1. 输入直播URL
2. 点击"开始播放"
3. 观察日志输出
4. 如果白屏，尝试"重新加载"按钮

**方案2：尝试不同的直播源**
测试这些URL：
- CCTV13: `https://tv.cctv.com/live/cctv13/`
- CCTV1: `https://tv.cctv.com/live/cctv1/`
- 其他支持网页播放的直播源

**方案3：使用直接流URL**
如果能获取到m3u8等直接流URL，在schedule.json中配置：
```json
{
  "type": "web",
  "url": "http://stream-server.com/live.m3u8"
}
```
系统会自动使用VLC播放器而不是浏览器

**方案4：检查显示配置**
运行显示配置工具：
```
scripts\display_settings.bat
```
确保：
- 显示模式设置正确
- 窗口大小合适
- 使用"测试显示"功能验证

### 调试技巧

1. **查看浏览器控制台**
   - 日志文件中会包含浏览器JavaScript控制台的输出
   - 搜索 "浏览器JS" 关键字

2. **逐步测试**
   - 先在普通浏览器中打开直播URL
   - 确认视频能正常播放
   - 再使用测试工具测试
   - 最后在实际系统中使用

3. **对比测试**
   - 测试多个不同的直播源
   - 找出哪些能播放，哪些不能
   - 分析差异

## 获取帮助

## 完全重新安装

如果问题持续存在，尝试完全重新安装：

1. 卸载所有Python包：
```
pip uninstall PyQt5 PyQtWebEngine python-vlc schedule requests flask -y
```

2. 重新安装：
```
cd C:\path\to\TimerPlay
scripts\install.bat
```

3. 测试：
```
scripts\test_imports.bat
```

4. 启动：
```
scripts\launcher.bat
```
